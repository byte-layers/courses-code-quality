# courses-code-quality

Les contenus du stack `code-quality` de byte_layers : la qualité du logiciel, des normes au pipeline
(modèle ISO 25010, référentiels français, dette technique, clean code, tests, mesure de la dette,
gates en CI, sécurité de la chaîne d'approvisionnement). Un dossier par contenu, à plat.

Le parcours du stack est décrit dans `stacks/code-quality/stack.yml`. Les fichiers de l'apprenant vont
dans `~/byte-layers/quality/`, et chaque contenu ne touche qu'à son propre sous-dossier ; les labs qui
mesurent le projet fil rouge travaillent dans `~/byte-layers/ai/todo-api`, laissé par le stack `ai-coding-agents`.

Les labs repartent du projet fil rouge `todo-api` et des branches laissées par le stack `ai-coding-agents`.
